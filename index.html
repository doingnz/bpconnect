Write settings to the device

An accepted write always restarts the device — once, and even when the value already matches. The restart is the acknowledgement: there is no separate success code. A rejected write changes nothing and does not say which setting was at fault.

Flow control applies to the uConnect S2B5232I Bluetooth adapter and to a Web Serial port. For hardware flow control to work the BP+ must have it enabled too (Menu → Setup → Hardware). Recommended on Android, where the link cannot keep up with 115200 baud during an XML transfer and data is otherwise lost. Other Bluetooth bridges manage flow control in their own firmware and ignore this setting.
Serial tracing logs every line sent and received in the pane below. It costs nothing when off and is the first thing to turn on when a device is not behaving.
